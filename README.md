# FranNotes

Study notes for Information Systems Engineering @ UTN-FRT, organized by subject. Written in Spanish, from my own coursework.

## Contents

Each folder is a subject: Análisis Matemático II, Matemática Superior, Comunicaciones, Diseño de Sistemas, Administración de Recursos, Auditoría, Economía, Ing. de Software, Investigación Operativa, Legislación, Data Eng, SSL, and programming notes.

Mostly Markdown + PDFs, plus `Apuntes de Programación.pdf` as a compiled digest.

## Use

Browse by folder. If something helped you pass, it already paid off.
